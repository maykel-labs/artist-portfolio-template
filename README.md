# Página de artista

Plantilla inicial para desarrollar una página web de presentación de un artista.

## Objetivo
Crear un sitio claro, accesible y adaptable a móviles para presentar la identidad, trayectoria y trabajos del artista.

## Estructura propuesta
```text
.
├── assets/
│   ├── images/
│   └── icons/
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── docs/
│   └── PLAN.md
└── index.html
```

## Secciones sugeridas
- Inicio y presentación.
- Biografía.
- Galería o portafolio.
- Proyectos y colaboraciones.
- Contacto y redes sociales.

## Tecnologías
HTML, CSS y JavaScript (por definir según las necesidades del proyecto).

## Estado
🟡 Estructura inicial. El contenido y la identidad visual se definirán durante el desarrollo.

## Desarrollo
1. Definir artista, público y objetivos.
2. Reunir textos e imágenes con permiso de uso.
3. Diseñar la estructura y los estilos.
4. Implementar interacciones y revisar accesibilidad.
5. Probar en móvil y escritorio.
